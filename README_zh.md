# OpenCodeGoBoard

[English](README.md) · **简体中文**

OpenCodeGoBoard 是一个本地优先的 OpenCode Go 额度与用量决策工具。它把官方额度窗口与本地同步记录结合起来，帮助你判断哪个额度窗口会最先成为瓶颈、额度能否撑到重置、当前更适合使用哪个账户或模型，以及本地历史数据是否完整。

## 主要能力

- 多账户额度、瓶颈窗口、续航预测和安全预算
- 用量同步、会话/项目归属、Token/成本/缓存分析
- 官方额度与本地记录对账、模型额度权重自动校准
- 可选阈值通知、脱敏诊断包、CSV 导出和校验后备份恢复
- 默认极简模式，可在**设置 → 功能模式**中按需开启统计、记录、额度智能、数据工具和高级同步
- 中英文界面、IANA 时区统计和夏令时支持
- Tauri + Rust + SQLite，不使用 Electron、Hono、Bun 后端或本地 HTTP 服务
- Auth Cookie 保存到 Windows 系统凭据库，而不是应用数据库

## 快速开始

1. 新安装默认进入**极简模式**；如果需要更多页面和高级功能，先打开**设置 → 功能模式**，或选择“完整”预设。
2. 打开**设置 → OpenCode 账户 → 添加账户**。
3. 在系统浏览器完成登录，从 `https://opencode.ai` 复制 `auth` Cookie，粘贴到 **Auth Cookie**。
4. 点击**测试**确认账户可用，再点击**同步**拉取最近使用记录。
5. 需要更早的历史记录时先开启**高级同步**，再使用**回填**，开始前选择最近 N 天、截至日期或全部历史。
6. Cookie 失效时点击**编辑**或**重新授权**；更新原账户不会删除历史数据。

## 四个功能区

### 1. 总览

总览是日常决策页面，集中展示账户可用性、最早额度瓶颈、各额度窗口、重置时间、近期 Token 用量、数据健康状态、额度对账事件，以及账户/模型建议。

需要立即刷新时使用**一键同步**。极简模式只做增量同步；开启“高级同步”后，按钮会同时执行 90 天历史回填。新账户的额度快照还不够时，续航预测显示“数据不足”属于正常情况，积累多次快照后才会形成较可靠的趋势。

### 2. 统计

（需先在**功能模式**中开启“用量统计”。）

统计页面用于比较输入、输出、推理、缓存读取、成本、请求数、模型、每日趋势和小时分布。可以使用时间范围和账户筛选器缩小范围。每天的起止边界、小时归属都会按照设置中选择的时区计算。

### 3. 使用记录

（需先在**功能模式**中开启“用量记录”。）

使用记录提供两种查看方式：

- **会话**：按会话和项目汇总请求，项目名称/目录/标题直接使用同步时 OpenCode 返回的信息，无需手动关联。
- **记录**：查看每次请求的账户、模型、Token 明细、成本和时间。

两种视图均支持账户筛选和分页。项目摘要卡会展示成本、缓存率和模型构成。

### 4. 设置

设置页面包含较多运行控制，可按下面的顺序理解：

- **功能模式**：选择极简或完整预设，或逐个开启五个功能组；极简下只显示下面的核心设置，高级区块会随对应开关出现。
- **语言**：选择中文、English 或跟随操作系统。
- **时区**：默认 `Asia/Shanghai`，也可以选择 `America/New_York` 等任意可用 IANA 时区。它会影响“今天”、日/小时统计、周期边界和所有时间显示。
- **外观与可读性**：选择主题、文字密度和高对比度模式。
- **系统行为**：设置关闭到托盘；额度通知随“额度智能与提醒”开关显示。
- **账户**：添加、启用/停用、测试、编辑/重新授权、同步、回填或删除账户。删除账户会同时删除其本地历史；Cookie 变化时应使用编辑，而不是删除。
- **自动同步**：决定是否后台定时同步；同步间隔随“高级同步”开关显示。
- **历史回填**：随“高级同步”开关显示，可选择最近 N 天、截至日期或全部历史；到达目标日期或历史末尾后自动停止。
- **数据管理**：随“数据与诊断工具”开关显示，可导出 CSV、备份完整 SQLite 数据库、恢复通过校验的备份，或下载不含凭据的诊断报告。
- **后端与更新**：随“数据与诊断工具”开关显示，可查看 Tauri IPC 运行状态、重启应用，以及检查已经配置的签名更新源。

## 隐私和数据

用量与额度数据保存在本地 SQLite 数据库中，账户凭据保存在 Windows Credential Manager。诊断包不会导出凭据和原始账户秘密。删除账户或恢复其他数据库前，建议先创建备份。

## 本地开发

需要 Node.js、pnpm、Rust 和 Windows WebView2 开发环境。

```bash
pnpm install
pnpm dev
```

验证与打包：

```bash
pnpm test
pnpm build
pnpm a11y:check
pnpm benchmark:db
pnpm dist
```

NSIS 安装包位于 `src-tauri/target/release/bundle/nsis/`。签名更新、校验和与回滚见 [docs/RELEASE.md](docs/RELEASE.md)，完成状态见 [docs/ROADMAP.md](docs/ROADMAP.md)，实测基准见 [docs/PERFORMANCE.md](docs/PERFORMANCE.md)。
