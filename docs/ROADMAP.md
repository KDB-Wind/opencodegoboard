## Tauri 迁移的建议边界

保留：React/Vite 页面、i18n、视觉组件、统计口径及已验证 SQL。

替换：Electron 窗口/托盘、preload、本地 Hono HTTP 服务、Bearer Token/CORS/端口发现、`better-sqlite3` 原生 Node 模块。

优先纵向切片：应用启动 → 系统凭据 → 单账户配额 → SQLite → usage 同步 → Dashboard。每个切片完成后再删除对应 Electron 实现。

## 2026-08-14 Tauri 体积探针

- 复用现有 1.07 MB 前端产物。
- Release 可执行文件：3.45 MB。
- NSIS 在线安装包：1.38 MB。
- WebView2 模式：`downloadBootstrapper`，不内置离线运行时。
- 首次干净构建约 5 分 43 秒；后续应在 CI 缓存 Cargo 依赖。

这些数字只证明桌面壳和分发目标成立，不代表完整应用最终仍为 1.38 MB。正式加入 SQLite、HTTP、凭据、托盘和更新组件后预计会增长，仍可将 20 MB 内作为工程目标。当前 Tauri 包尚未移植业务后端，不能作为正式可用版本发布。
